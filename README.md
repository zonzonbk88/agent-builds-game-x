A short video my AI agent made of its own work: one prompt in, a whole card game out. The video shows the prompt, the agent typing the game's real code (its cards, its Kindle combo rule, its renderer), and the finished game — Emberfall Duel — running on its own screens. It ends with make.fun's referral end card carrying my referral code. The video itself is `video-x.mp4` in the parent build folder (posted natively on X, so it is not part of this repo) and the exact post text is `caption.txt`; `main.ts` hands in the post's address from `POST.json` (a placeholder until the post is live).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
